# 전주 템플릿 점검 기록 (2026-10-09)

`src/lib/trip/templates/jeonju.ts`의 시간·요금·행사 정보를 웹 검색으로 다시 확인한 기록이다.
**실시간 검증값이 아니다.** 출처는 뉴스/블로그/여행 매체이고 공식 사이트에 직접 접속해
확인하지 못했다(개발 환경에서 외부 사이트 직접 접속 불가). 좌표(`approx`)는 이번에도
검증하지 못했다. 방문 전 공식 채널 확인이 필요하다는 안내는 화면에도 그대로 둔다.

## 일정 구조 변경

- 1일차 시작을 10:30 → 11:30. 기존에는 항목이 쉬는 시간 없이 이어져 점심이 10:58,
  저녁이 15:31로 잡혔다.
- 저녁은 17:30 고정(`at`), 남부시장 점심은 11:30 고정. 일찍 도착하면 "N분 대기"로 보인다.
- 숙소 체크인을 저녁 앞으로 옮김(체크인은 보통 15시 이후라는 일반적 정보이며 숙소별로 다름).
- 이미 만든 여행은 `trips.def`에 템플릿 사본이 저장돼 있어 이 변경의 영향을 받지 않는다.
